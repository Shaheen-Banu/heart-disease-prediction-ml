# Heart Disease Prediction Using Machine Learning

## Project Overview

This project predicts the presence of heart disease using machine learning algorithms. The objective is to compare multiple classification models and identify the best-performing model.

## Dataset

* Source: Kaggle Heart Disease Dataset
* Original Records: 1025
* Duplicate Records Removed: 723
* Final Records Used: 302
* Features: 13
* Target Variable: Heart Disease (0/1)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Machine Learning Models

1. Logistic Regression
2. Decision Tree
3. Random Forest

## Model Performance

| Model               | Accuracy |
| ------------------- | -------- |
| Logistic Regression | 80.33%   |
| Decision Tree       | 80.33%   |
| Random Forest       | 75.41%   |

## Key Findings

* Logistic Regression achieved the best overall performance.
* Duplicate records significantly affected model evaluation.
* Feature importance analysis identified major predictors of heart disease.
